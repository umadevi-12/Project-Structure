# Electronics E-commerce Search Microservice

A Node.js/Express microservice for electronics e-commerce platforms targeting Tier-2 and Tier-3 cities in India. Features intelligent search ranking based on multiple factors including relevance, price, ratings, and metadata.

## Features

- ✅ Product catalog management with metadata support
- ✅ In-memory storage with auto-indexing
- ✅ Intelligent search with custom ranking algorithm
- ✅ Support for user intents (cheap, price-range, feature-based)
- ✅ Spelling mistake correction
- ✅ RESTful APIs
- ✅ Performance optimized (< 1000ms response time)
- ✅ Comprehensive error handling

## Tech Stack

- Node.js
- Express.js
- Natural Language Processing (natural library)
- In-memory storage with Map
- Winston for logging
- Helmet for security
